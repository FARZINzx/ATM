   <h1>ATM Project</h1>
    <p>Welcome to the ATM Project repository! This project simulates the basic functionalities of an Automated Teller Machine (ATM) using the C programming language.</p>
    <h2>Introduction</h2>
    <p>The ATM Project is a simple console-based application designed to replicate basic ATM functionalities such as checking account balance, withdrawing money, and depositing money.</p>
    <h2>Features</h2>
    <ul>
        <li>Check account balance</li>
        <li>Withdraw money</li>
        <li>Deposit money</li>
        <li>Simple user authentication</li>
        <li>Transaction history</li>
    </ul>
    <h2>Installation</h2>
    <p>To install and run the ATM Project, follow these steps:</p>
    <ol>
        <li>Clone the repository:</li>
        <pre><code>git clone https://github.com/FARZINzx/ATM.git</code></pre>
        <li>Navigate to the project directory:</li>
        <pre><code>cd ATM</code></pre>
        <li>Compile the project:</li>
        <pre><code>gcc -o atm atm.c</code></pre>
        <li>Run the application:</li>
        <pre><code>./atm</code></pre>
    </ol>
    <h2>Usage</h2>
    <p>Once the application is running, follow the on-screen instructions to use the ATM functionalities. You will be able to log in with your credentials, check your balance, withdraw or deposit money, and view your transaction history.</p>
